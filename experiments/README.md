# Experiments

Each directory here is a feature you can run on an X-M1 from RAM: a `hooks.json` naming stock functions to run in front of, and a `lib.rs` and/or C and assembly with the handlers. [`hello`](hello/) is the template and [`sdk`](sdk/) the shared header and linker script. [Build and test your own X-M1 feature](../docs/experimenting-on-your-x-m1.md) walks through writing one, trying it in the emulator and pushing it to a camera.
